# 本機執行步驟（Windows）

以下步驟讓您在自己的電腦上把系統跑起來、登入並匯入舊名冊。約需 30 分鐘，大部分時間在等安裝。

## 步驟 1：安裝 Node.js

1. 到 <https://nodejs.org> 下載 **LTS 版本**（22.x），安裝時全部用預設選項。
2. 安裝完成後開啟「PowerShell」（開始功能表搜尋 PowerShell），輸入以下指令確認版本：

   ```powershell
   node -v
   npm -v
   ```

   看到 `v22.x.x` 與 `10.x.x` 之類的版本號即可。

## 步驟 2：取得程式碼

1. 開啟 GitHub Desktop，確認 Current repository 是 `Church-Directory`。
2. 點 **Fetch origin**。
3. 點 Current branch 下拉選單，選擇 `claude/compassionate-meitner-2c6jxb`（若列表中顯示為 `origin/claude/...`，點它會自動建立本機分支）。
4. 選單 **Repository → Open in PowerShell**（或 Show in Explorer 後在資料夾位址列輸入 `powershell`）。之後的指令都在這個視窗執行，路徑應是 `C:\Users\Joseph Chen\Documents\Source Code\Github\JosephChenUlink\Church-Directory`。

## 步驟 3：建立 Supabase 專案（資料庫）

本機不需要安裝 PostgreSQL，直接用 Supabase 的免費方案當資料庫。

1. 到 <https://supabase.com> 用 GitHub 帳號登入，點 **New project**。
2. 填寫：
   - Name：`church-directory`
   - Database Password：點 **Generate a password**，**立刻複製存起來**（之後看不到）
   - Region：選 `West US (North California)`（離 San Jose 最近）
3. 等 1 到 2 分鐘專案建立完成。
4. 點畫面上方的 **Connect** 按鈕，在 **Connection string** 分頁選 **Transaction pooler**，複製那串 `postgresql://postgres.xxxx:[YOUR-PASSWORD]@...:6543/postgres`，把 `[YOUR-PASSWORD]` 換成剛才的密碼。這就是 `DATABASE_URL`。

## 步驟 4：建立設定檔 .env

1. 在 PowerShell 執行：

   ```powershell
   Copy-Item .env.example .env
   notepad .env
   ```

2. 記事本會打開 `.env`，修改以下幾行（其餘先不動）：

   ```
   CHURCH_SLUG=san-jose
   NEXT_PUBLIC_CHURCH_NAME=聖荷西教會
   DATABASE_URL=（貼上步驟 3 的連線字串）
   BETTER_AUTH_SECRET=（貼上一串隨機文字，產生方式見下方）
   STORAGE_DRIVER=local
   SEED_ADMIN_EMAIL=（您的電子郵件）
   SEED_ADMIN_PASSWORD=（您要用的登入密碼，至少 8 個字）
   SEED_ADMIN_NAME=（您的姓名）
   ```

   產生 `BETTER_AUTH_SECRET` 的隨機文字，在 PowerShell 執行這行並複製結果：

   ```powershell
   -join ((48..57)+(65..90)+(97..122) | Get-Random -Count 48 | ForEach-Object {[char]$_})
   ```

3. 存檔並關閉記事本。

> `STORAGE_DRIVER=local` 表示照片存在專案資料夾的 `storage` 子資料夾，本機試用足夠。正式上線時改為 `supabase`，見「docs/新教會上線步驟.md」。

## 步驟 5：安裝套件並建立資料表

在 PowerShell 依序執行（每行等它跑完再下一行）：

```powershell
npm install
npm run db:migrate
npm run db:seed
```

- `npm install` 約 1 到 3 分鐘。
- `db:migrate` 會在 Supabase 建立所有資料表，看到 `migrations applied successfully` 即可。
- `db:seed` 會建立教會與您的管理員帳號，看到 `已建立管理員` 即可。

## 步驟 6：匯入舊名冊

先試跑看報告，確認沒有錯誤訊息，再正式匯入。順序是先 2017 年、再 2016 年：

```powershell
npm run import:excel -- "docs/San Jose Church Member Directory 2017-10-02.xlsx" --dry-run
npm run import:excel -- "docs/San Jose Church Member Directory 2017-10-02.xlsx"
npm run import:excel -- "docs/San Jose Church Directory 2016.xlsx" --only-new --label "2016 名冊" --note "此人僅出現在 2016 年名冊，2017 年名冊已無此人，請確認目前狀態"
```

最後會顯示「資料庫目前會員總數：291」。

## 步驟 7：啟動系統

```powershell
npm run dev
```

看到 `Ready` 後，用瀏覽器開啟 <http://localhost:3000>，用步驟 4 填的電子郵件與密碼登入。

要停止系統，在 PowerShell 視窗按 `Ctrl + C`。下次要再啟動，只需開啟 PowerShell 到專案資料夾，執行 `npm run dev` 即可，步驟 5 與 6 不必重做。

## 步驟 8：登入後建議先做的事

1. 到「我的帳號」更改密碼，並在手機或電腦上建立 Passkey。
2. 到「會員」頁面隨機點幾位會友，確認資料正確。
3. 到「使用者管理」為同工建立帳號。

## 常見問題

- **`npm` 不是內部或外部命令**：Node.js 沒裝好或 PowerShell 是安裝前開的，關掉 PowerShell 重開。
- **`db:migrate` 出現 `password authentication failed`**：`DATABASE_URL` 裡的密碼不對，確認 `[YOUR-PASSWORD]` 已整段換掉，含中括號。
- **`db:migrate` 出現 `ECONNREFUSED` 或逾時**：連線字串貼錯或網路被防火牆擋住，確認用的是 port 6543 的 Transaction pooler 字串。
- **瀏覽器顯示登入失敗**：確認 `.env` 的 `SEED_ADMIN_EMAIL` 與您輸入的一致，密碼至少 8 個字。
- **改了 `.env` 之後沒有生效**：按 `Ctrl + C` 停止後重新 `npm run dev`。
